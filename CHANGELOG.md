# Changelog

Changes to the Gifted fan wiki and Bastian's status tracker, newest first.

## 2026-10-18
- Added a **Spreadsheet** button to the top bar that opens the Google Sheet the tracker reads from.
- Renamed the **Royal Road** button to **Ellake's Royal Road**.

## 2026-10-17
- Data: added the Path of Weapon Mastery rows the author added to chapter 142 (Weapon Mastery I–II; the Claw, Shieldwork and Daggers completed; three new advanced paths unlocked).

## 2026-10-16
- Data: added chapter 142 to the Achievements tab (Path of Conversation corrected to tier V after the author confirmed a typo).

## 2026-10-14
- Tracker now reads the **Achievements tab** of the Google Sheet directly every time it loads, so new chapters only need to be added to the sheet. If the sheet can't be reached, the page uses its saved copy.
- Added three columns to the Achievements tab (Achievement?, Path Progress, Status Changes) so the tracker can rebuild every earlier status screen exactly.
- Put the tracker inside the wiki layout (top bar and footer).
- Chapter picker labels simplified to "Ch. N (age)", with "status" added when a status screen appears that chapter; chapter 1 shows its gestation stages.
- Layout: uses the full page width on large screens and switches to two columns on medium screens instead of squishing.
- Tracker published on GitHub Pages from the `tracker` branch.

## Before 2026-10-14
- First version of Bastian's status sheet, tracked chapter by chapter through chapter 140.
